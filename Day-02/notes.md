# Day 02 - Modules and pip in Python

## Modules in Python

A module is like a code library which we can use in our Python program. It contains code written by someone else that we can use instead of writing everything from scratch.

There are two types of modules:

### 1. Built-in Modules

These modules are already available with Python. We can import and use them without installing them separately.

Examples:
- `math`
- `os`
- `random`

### 2. External Modules

These modules are created by other developers. We can install them using package managers like `pip` or `conda`.

For example, we can install pandas using:

```bash
pip install pandas
```

## Using a Module

We use `import` to import a module in Python.

```python
import pandas
```

After importing a module, we can use it according to its documentation.

## Important Points

- Modules help us use code written by others.
- Built-in modules come with Python.
- External modules need to be installed.
- `pip` is used to install Python packages.
- We use `import` to use a module.
