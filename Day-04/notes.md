# Day 04 - Comments and Escape Sequences

Today I learned about Comments and Escape Sequences in Python.

## Comments

Comments are used to write something in the code that Python does not execute.

### Single Line Comments

We can use `#` for a single line comment.

Example:

```python
# My Name is Raja Muneeb Ahmed
# I am 22 Years old
```

### Multiple Line Comments

For multiple lines, we can use triple quotes:

```python
'''
My name is Raja Muneeb Ahmed
I am 22 years old
'''
```

## Escape Sequences

Escape sequences are used to write special characters inside a string.

For example:

- `\n` is used for a new line.
- `\"` is used to print double quotes inside a string.

Example:

```python
print("I am a \"Good Boy\"\nand this viewer is also a good Boy/Girl")
```

## What I Learned Today

Today I learned about single line comments, multiple line comments and escape sequences like `\n` and `\"`.
